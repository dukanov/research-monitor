### [Task Vector in TTS: Toward Emotionally Expressive Dialectal Speech Synthesis](https://arxiv.org/abs/2512.18699)

**Релевантность:** 70.0%

Исследователи предложили метод Hierarchical Expressive Vector (HE-Vector) для синтеза диалектной речи с эмоциональной окраской: сначала создаются отдельные векторы задач для диалекта и эмоций (E-Vector), затем они иерархически объединяются. Ключевое отличие — возможность синтеза речи, сочетающей диалект и эмоции, без необходимости в данных с совместной разметкой, что решает проблему дефицита таких данных. Результаты показывают хорошее качество диалектного синтеза и многообещающие результаты для эмоционально-диалектного синтеза в zero-shot режиме.

**Ключевые моменты:**

- Предложен метод Hierarchical Expressive Vector (HE-Vector) - двухэтапный подход для синтеза эмоционально выразительной диалектной речи без необходимости совместно размеченных данных
- Основная проблема решается через независимое моделирование диалектных и эмоциональных стилей с помощью векторов задач, которые затем иерархически интегрируются
- Метод достигает превосходных результатов в синтезе диалектов и многообещающие результаты в zero-shot синтезе эмоционально выразительной диалектной речи
- Исследование устраняет главное препятствие в области кросс-стилевого синтеза - нехватку диалектных данных с эмоциональными метками

### [JoyVoice: Long-Context Conditioning for Anthropomorphic Multi-Speaker Conversational Synthesis](https://arxiv.org/abs/2512.19090)

**Релевантность:** 70.0%

JoyVoice представляет собой модель синтеза речи для многоспикерных разговоров (до 8 говорящих), использующую единую E2E-Transformer-DiT архитектуру с авторегрессивными скрытыми представлениями для диффузионного входа. Основное отличие от существующих каскадных систем — целостная end-to-end оптимизация и MM-токенизатор с частотой 12.5 Гц, объединяющий семантические и акустические потери для моделирования многоязычной речи (китайский, английский, японский, корейский). Модель демонстрирует улучшения в просодической непрерывности и естественности паралингвистических элементов, хотя ограничения подробно не обсуждаются.

**Ключевые моменты:**

- JoyVoice представляет новую модель для синтеза речи до 8 говорящих одновременно, преодолевая ограничения диадических взаимодействий существующих систем
- Использует единую E2E-Transformer-DiT архитектуру с прямым применением авторегрессивных скрытых представлений для диффузионных входов
- MM-Tokenizer работает на низкой частоте 12.5 Гц и интегрирует многозадачные семантические потери и потери MMSE для эффективного моделирования семантической и акустической информации
- Достигает state-of-the-art результатов в многоязычной генерации (китайский, английский, японский, корейский) и zero-shot клонировании голоса
- Демонстрирует значительные улучшения в просодической непрерывности для длинной речи и ритмическом богатстве многоговорящих разговоров
