### [X-Voice: Enabling Everyone to Speak 30 Languages via Zero-Shot Cross-Lingual Voice Cloning](https://arxiv.org/abs/2605.05611)

**Relevance:** 70.0%

X-Voice is a 0.4B parameter multilingual voice cloning model that enables zero-shot voice cloning across 30 languages using IPA as a unified phonetic representation, trained on 420K hours of multilingual data. The key innovation is a two-stage training paradigm: first standard conditional flow-matching training, then fine-tuning on synthesized audio pairs with masked text prompts, which eliminates the need for transcripts of reference audio during inference. Despite being significantly smaller, X-Voice achieves performance comparable to billion-scale models like Qwen3-TTS while outperforming other flow-matching based systems.

**Key points:**

- Introduces a novel two-stage training paradigm that eliminates the need for prompt text transcripts in zero-shot voice cloning, avoiding complex preprocessing like forced alignment
- Achieves comparable performance to billion-scale models (like Qwen3-TTS) using only 0.4B parameters, demonstrating significant efficiency improvements
- Extends F5-TTS architecture with dual-level language identifier injection and decoupled Classifier-Free Guidance scheduling to enable multilingual synthesis across 30 languages
- Trained on massive 420K-hour multilingual corpus using International Phonetic Alphabet (IPA) as unified phonetic representation for cross-lingual consistency
- Open-sources all resources and outperforms existing flow-matching based multilingual systems like LEMAS-TTS in both subjective and objective evaluations

### [Minimizing Modality Gap from the Input Side: Your Speech LLM Can Be a Prosody-Aware Text LLM](https://arxiv.org/abs/2605.05927)

**Relevance:** 70.0%

This paper introduces TextPro-SLM, which reduces the modality gap between speech and text LLMs by focusing on the input side rather than output generation - using a unified encoder (WhisperPro) that produces both synchronized text tokens and prosody embeddings fed into an LLM backbone. Unlike previous work that tried to make speech generation more text-like, this approach makes speech input more closely resemble prosody-aware text input while preserving paralinguistic understanding capabilities. The method achieves strong performance with only ~1,000 hours of training audio, demonstrating data efficiency, though this relatively small dataset size could limit broader applicability.

**Key points:**

- Proposes TextPro-SLM, a novel approach that reduces modality gap from the input side by making spoken input resemble prosody-aware text LLM input, contrary to prior work focusing on output-side improvements
- Introduces WhisperPro, a unified speech encoder that produces synchronized text tokens and prosody embeddings, enabling better alignment between speech and text modalities
- Achieves the lowest modality gap among leading Speech LLMs at both 3B and 7B scales while delivering strong paralinguistic understanding performance
- Demonstrates high data efficiency by achieving these gains with only approximately 1,000 hours of LLM training audio, suggesting input-side gap reduction is more effective than previous approaches

### [WavCube: Unifying Speech Representation for Understanding and Generation via Semantic-Acoustic Joint Modeling](https://arxiv.org/abs/2605.06407)

**Relevance:** 70.0%

WavCube presents a unified speech representation that supports both understanding and generation tasks by combining semantic and acoustic information in a compact continuous latent space derived from SSL encoders. The key innovation is a two-stage training approach: first creating a semantic bottleneck to filter redundant information from SSL features, then injecting acoustic details while maintaining semantic grounding through an anchoring loss. The method achieves near-WavLM performance on speech understanding benchmarks despite 8x compression, matches existing acoustic representations for reconstruction quality, and delivers state-of-the-art zero-shot TTS with faster convergence, demonstrating the viability of truly unified speech systems.

**Key points:**

- WavCube introduces a unified continuous latent representation derived from SSL speech encoders that simultaneously supports speech understanding, reconstruction, and generation, addressing the fragmentation between semantics-oriented and acoustic-oriented features in current systems
- The novel two-stage training scheme first creates a semantic bottleneck to filter off-manifold redundancy from raw SSL features, then injects fine-grained acoustic details while using semantic anchoring loss to maintain semantic grounding
- Achieves remarkable efficiency with 8x dimensional compression compared to WavLM while maintaining comparable SUPERB performance, plus delivers state-of-the-art zero-shot TTS with markedly faster training convergence
- Systematic ablations reveal that the approach resolves two intrinsic flaws of SSL features for generative modeling, providing insights for future unified speech system development

### [MiniCPM-o 4.5: Towards Real-Time Full-Duplex Omni-Modal Interaction](https://huggingface.co/papers/2604.27393)

**Relevance:** 70.0%

MiniCPM-o 4.5 introduces "Omni-Flow," a unified streaming framework that enables real-time full-duplex multimodal interaction by aligning vision, audio, and text inputs/outputs along a shared temporal axis, allowing the 9B parameter model to simultaneously perceive and respond rather than alternating between listening and speaking phases. This approach differs from existing multimodal models by supporting proactive behaviors (like issuing reminders) based on continuous scene understanding, moving beyond reactive turn-based interactions. While achieving strong performance comparable to much larger models and running efficiently on edge devices, it still approaches but doesn't quite match the capabilities of leading proprietary models like Gemini 2.5 Flash.

**Key points:**

- Introduces Omni-Flow, a unified streaming framework that aligns omni-modal inputs and outputs along a shared temporal axis, enabling real-time full-duplex interaction
- Achieves simultaneous perception and response capabilities, eliminating the alternating phases of conventional turn-based interaction paradigms
- Demonstrates proactive behavior by issuing reminders and comments based on continuous scene understanding, moving beyond reactive-only responses
- With only 9B parameters, approaches Gemini 2.5 Flash performance in vision-language tasks while running on edge devices with <12GB RAM
- Converts conventional turn-based multimodal interaction into a time-aligned process, allowing proactive behaviors to emerge within the same framework
