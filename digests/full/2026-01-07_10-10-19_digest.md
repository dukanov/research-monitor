### [Segment-Aware Conditioning for Training-Free Intra-Utterance Emotion and Duration Control in Text-to-Speech](https://arxiv.org/abs/2601.03170)

**Релевантность:** 75.0%

Авторы предлагают метод для контроля эмоций и длительности речи внутри одного высказывания в TTS без дополнительного обучения, используя segment-aware conditioning с каузальным маскированием и монотонной фильтрацией выравнивания. Основное отличие от существующих подходов — возможность fine-grained контроля на уровне сегментов внутри высказывания, а не только между высказываниями, при работе с предобученными zero-shot TTS моделями. Для автоматической генерации промптов авторы создали датасет из 30,000 образцов с аннотациями эмоций и длительности.

**Ключевые моменты:**

- Предложен метод без дополнительного обучения для управления эмоциями и длительностью внутри высказывания в TTS, в отличие от существующих методов, ограниченных управлением между высказываниями
- Разработана стратегия сегментно-осведомленного эмоционального кондиционирования с каузальным маскированием и фильтрацией монотонного потокового выравнивания для плавных переходов эмоций
- Создан датасет из 30,000 образцов с аннотациями эмоций и длительности для автоматического построения промптов с помощью LLM
- Метод достигает современного уровня точности внутриутказательной консистентности при сохранении базового качества речи исходной TTS модели

### [Towards Fine-Grained and Multi-Granular Contrastive Language-Speech Pre-training](https://arxiv.org/abs/2601.03065)

**Релевантность:** 75.0%

Авторы представляют FCaps — крупномасштабный датасет с детализированными текстовыми описаниями стилей речи (47k часов речи, 19M аннотаций) и модель CLSP для контрастивного предобучения на речи и тексте с мультигранулярными представлениями. Ключевое отличие — end-to-end pipeline для аннотации, который напрямую связывает детальные описания с аудио, избегая ошибок каскадных LLM-подходов, и интеграция глобального и детального контроля в едином представлении. Оценка качества аннотаций полагается на LLM-as-a-judge, что может быть ограничением методологии.

**Ключевые моменты:**

- Представлен датасет FCaps с детализированными описаниями речевых стилей (47 тыс. часов речи, 19 млн аннотаций), созданный через новый end-to-end пайплайн, который напрямую связывает подробные описания с аудио
- Разработана модель CLSP для контрастивного предобучения язык-речь, интегрирующая глобальный и детализированный контроль для создания единых представлений на множественных уровнях детализации
- Новый подход избегает накопления ошибок, характерного для существующих каскадных пайплайнов с переписыванием через LLM
- Модель демонстрирует сильную производительность в задачах поиска речь-текст, zero-shot паралингвистической классификации и оценки схожести речевых стилей с хорошим соответствием человеческим суждениям

### [MoE Adapter for Large Audio Language Models: Sparsity, Disentanglement, and Gradient-Conflict-Free](https://arxiv.org/abs/2601.02967)

**Релевантность:** 70.0%

Авторы предлагают MoE-Adapter — разреженную архитектуру смеси экспертов для адаптации больших языковых моделей к аудио-данным, которая использует динамическую маршрутизацию аудио-токенов к специализированным экспертам для разных типов акустической информации (речь, музыка, окружение). В отличие от существующих плотных адаптеров с общими параметрами, которые создают конфликты градиентов при обучении на разнородных акустических паттернах, MoE-архитектура позволяет избежать этой проблемы путем разделения обучения разных аспектов звука. Подход показывает превосходство над базовыми методами при сопоставимых вычислительных затратах.

**Ключевые моменты:**

- Предложена архитектура MoE-Adapter - разреженная система смеси экспертов для решения проблемы конфликта градиентов при обработке гетерогенной акустической информации в больших языковых моделях
- Ключевое открытие: акустическая информация внутренне гетерогенна, объединяя различные атрибуты (речь, музыку, контекст окружения), что создает конфликт градиентов в существующих плотных адаптерах
- Динамический механизм маршрутизации направляет аудио-токены к специализированным экспертам для комплементарных подпространств признаков, сохраняя общих экспертов для глобального контекста
- Экспериментально подтверждено превосходство над плотными линейными базовыми методами как в семантических, так и в паралингвистических аудио-задачах при сопоставимых вычислительных затратах
