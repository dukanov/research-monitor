### [DeepASMR: LLM-Based Zero-Shot ASMR Speech Generation for Anyone of Any Voice](https://arxiv.org/abs/2601.15596)

**Релевантность:** 75.0%

DeepASMR представляет первую систему для zero-shot генерации ASMR речи, использующую двухступенчатый подход с LLM для кодирования контента/стиля и flow-matching декодером для реконструкции тембра. Ключевое отличие — система требует только короткий образец обычной речи целевого говорящего для создания высококачественного ASMR в его голосе, без необходимости в данных шепота от этого говорящего. Авторы также создали специализированный датасет DeepASMR-DB объемом 670 часов и новый протокол оценки, включающий анализ безголосой речи.

**Ключевые моменты:**

- Первая система для генерации ASMR-речи с нулевым обучением, способная синтезировать высококачественный ASMR из короткого фрагмента обычной речи любого диктора без необходимости в шепотных данных для обучения
- Ключевое открытие: дискретные речевые токены обеспечивают мягкую факторизацию ASMR-стиля от тембра диктора, что позволяет разделить стилистические и акустические характеристики
- Создание DeepASMR-DB - масштабного корпуса ASMR-речи объемом 670 часов на английском и китайском языках для обучения и оценки систем
- Двухэтапная архитектура с использованием большой языковой модели для кодирования содержания и стиля, и flow-matching декодера для реконструкции тембра
- Новый протокол оценки, интегрирующий объективные метрики, перцептивные тесты, LLM-оценки и анализ неозвученной речи для комплексной оценки качества ASMR

### [Qwen3-TTS Technical Report](https://arxiv.org/abs/2601.15621)

**Релевантность:** 70.0%

Qwen3-TTS представляет семейство многоязычных TTS-моделей с поддержкой 3-секундного клонирования голоса, описательного управления синтезом и потокового воспроизведения в реальном времени. Ключевые отличия — dual-track архитектура с двумя специализированными токенизаторами (25Hz для семантики и 12Hz для ультра-низкой задержки 97мс) и обучение на 5 миллионах часов речи на 10 языках. В техническом отчёте не приводятся детальные сравнения с существующими методами.

**Ключевые моменты:**

- Представлена новая архитектура с двумя параллельными языковыми моделями для синтеза речи в реальном времени, использующая два различных токенизатора речи
- Достигнуто клонирование голоса всего за 3 секунды с возможностью управления через текстовые описания для создания совершенно новых голосов
- Модель обучена на более чем 5 миллионах часов речевых данных на 10 языках с двумя специализированными токенизаторами: 25 Гц для семантического содержания и 12 Гц для экстремального сжатия
- Достигнута ультра-низкая задержка потокового воспроизведения с эмиссией первого пакета за 97 миллисекунд благодаря 16-слойной мульти-кодбук архитектуре
- Показана передовая производительность на разнообразных объективных и субъективных тестах, включая многоязычные наборы данных и специализированные бенчмарки для длинной речи

*arxiv_id: 2601.15621 | published: Fri, 23 Jan 2026 00:00:00 -0500 | authors: Unknown | categories: cs.SD, cs.CL, eess.AS*

### [EmotionThinker: Prosody-Aware Reinforcement Learning for Explainable Speech Emotion Reasoning](https://arxiv.org/abs/2601.15668)

**Релевантность:** 70.0%

Исследователи предлагают EmotionThinker — модель для распознавания эмоций в речи через рассуждения с использованием обучения с подкреплением, вместо простой классификации. Ключевые отличия: улучшенное восприятие просодии (которое слабо у современных речевых LLM), создание датасета EmotionCoT-35K с аннотациями Chain-of-Thought, и новый метод GRPO-PTR, который оценивает качество рассуждений динамически, а не только финальный результат. Подход позволяет получать интерпретируемые объяснения эмоциональных предсказаний на основе акустических признаков.

**Ключевые моменты:**

- Впервые переформулировано распознавание эмоций в речи как задача глубокого рассуждения с использованием обучения с подкреплением, а не простой классификации
- Создан датасет EmotionCoT-35K с аннотациями Chain-of-Thought для эмоционального рассуждения с детализированными описаниями акустических сигналов
- Обнаружено, что современные речевые большие языковые модели имеют слабое восприятие просодии, хотя просодические сигналы являются фундаментальными для интерпретации эмоций
- Разработан метод GRPO-PTR с прогрессивным доверительным весом для оценки качества рассуждений, который динамически корректирует награды на основе соответствия между рассуждением и результатом
- Достигнуто превосходство над предыдущими методами как в точности распознавания эмоций, так и в качестве объяснений, продвигая область к интерпретируемому мультимодальному рассуждению

### [FlashLabs Chroma 1.0: A Real-Time End-to-End Spoken Dialogue Model with Personalized Voice Cloning](https://huggingface.co/papers/2601.11141)

**Релевантность:** 70.0%

Chroma 1.0 — первая открытая модель для диалогов в режиме реального времени, которая объединяет низкую задержку (менее секунды) с высококачественным клонированием голоса через чередующуюся схему текстово-аудио токенов (1:2). Отличается от существующих решений возможностью потокового генерирования и лучшим сохранением идентичности говорящего (улучшение на 10,96% по сравнению с человеческим базовым уровнем). Модель достигает коэффициента реального времени 0,43 при сохранении качества рассуждений и диалоговых способностей.

**Ключевые моменты:**

- Первая открытая модель диалоговой системы в реальном времени, которая объединяет низколатентное взаимодействие с высококачественным клонированием персонализированного голоса
- Использует чередующееся расписание текстово-аудио токенов (1:2) для поддержки потоковой генерации с задержкой менее секунды
- Достигает 10,96% относительного улучшения схожести голоса по сравнению с человеческим базовым уровнем при коэффициенте реального времени 0,43
- В отличие от предыдущих моделей с ограниченным сохранением идентичности говорящего, поддерживает персонализированный синтез голоса в многоходовых диалогах
- Код и модели находятся в открытом доступе на GitHub и HuggingFace
