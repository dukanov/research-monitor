### [MambaVoiceCloning: Efficient and Expressive Text-to-Speech via State-Space Modeling and Diffusion Control](https://arxiv.org/abs/2604.00292)

**Relevance:** 70.0%

**MambaVoiceCloning** proposes a text-to-speech system that uses state-space models (Mamba) exclusively for all conditioning components—text encoding, temporal modeling, and prosody control—while maintaining a diffusion-based mel-spectrogram generator. Unlike previous Mamba-TTS hybrids that still rely on attention mechanisms, this approach achieves fully SSM-only conditioning at inference with linear time complexity and bounded memory usage, showing modest but consistent quality improvements over StyleTTS2 and other baselines. The main limitation is that diffusion processing remains the primary latency bottleneck, so overall inference speed gains are limited despite more efficient conditioning.

**Key points:**

- MambaVoiceCloning introduces the first fully SSM-only conditioning path for diffusion-based TTS, completely eliminating attention and RNN layers across text, rhythm, and prosody modules at inference time
- Unlike prior Mamba-TTS hybrid systems, MVC achieves linear-time O(T) conditioning with bounded activation memory and enables practical finite look-ahead streaming capabilities
- The system demonstrates modest but statistically reliable improvements over StyleTTS2, VITS, and Mamba-attention hybrids across MOS/CMOS, F0 RMSE, MCD, and WER metrics while reducing encoder parameters to 21M and improving throughput by 1.6x
- Despite SSM-only conditioning improvements in memory footprint and stability, diffusion remains the dominant latency bottleneck in the overall TTS pipeline

### [Measuring Prosody Diversity in Zero-Shot TTS: A New Metric, Benchmark, and Exploration](https://arxiv.org/abs/2509.19928)

**Relevance:** 70.0%

This paper introduces ProsodyEval, a human-rated dataset of 1000 TTS samples, and proposes DS-WED (Discretized Speech Weighted Edit Distance), a new metric that measures prosody diversity using weighted edit distance over semantic speech tokens. DS-WED shows substantially higher correlation with human prosody judgments compared to existing acoustic metrics, and the authors use it to benchmark current TTS systems and analyze factors affecting prosodic variation. The work reveals that current large audio language models still have limited ability to capture prosodic variations.

**Key points:**

- Introduces ProsodyEval dataset with 1000 speech samples from 7 TTS systems and 2000 human ratings, addressing the gap in reliable prosody diversity quantification
- Proposes DS-WED (Discretized Speech Weighted Edit Distance) metric that achieves substantially higher correlation with human judgments than existing acoustic metrics by using weighted edit distance over semantic tokens
- Reveals that current large audio language models (LALMs) remain limited in capturing prosodic variations despite advances in the field
- Identifies key factors influencing prosody diversity including generative modeling paradigms, duration control, and reinforcement learning through systematic exploration

### [HumeAI/mlx-tada-3b](https://huggingface.co/HumeAI/mlx-tada-3b)

**Relevance:** 75.0%

TADA is a text-to-speech synthesis model that uses "text-acoustic dual alignment" to create a unified speech-language model, synchronizing speech and text representations in a single coherent stream with 1:1 alignment, built on Llama 3.2 3B. The key innovation appears to be this integrated dual-alignment approach rather than treating text and audio as separate modalities, supporting 10 languages including English, Chinese, Japanese, and several European languages. The model requires substantial memory (6-17GB depending on quantization) and is optimized specifically for Apple Silicon hardware using the MLX framework.

**Key points:**

- TADA introduces a novel unified speech-language model that synchronizes speech and text into a single cohesive stream via 1:1 text-acoustic dual alignment, representing a new paradigm for speech synthesis
- The model supports 10 languages (English, French, German, Spanish, Portuguese, Italian, Polish, Japanese, Chinese, Arabic) on a single 3B parameter Llama-based architecture
- 4-bit quantization achieves roughly 10x faster inference with 60% memory reduction (from ~17GB to ~6GB) while maintaining minimal quality loss, making it practical for consumer Apple Silicon devices
- The architecture consists of multiple specialized components: LLM + VibeVoice head (7.6GB), Aligner (852MB), Decoder/DAC (226MB), and Encoder (178MB), totaling ~8.9GB in bfloat16 format

### [Aratako/Irodori-TTS-500M-v2-VoiceDesign](https://huggingface.co/Aratako/Irodori-TTS-500M-v2-VoiceDesign)

**Relevance:** 70.0%

Irodori-TTS-500M-v2-VoiceDesign is a Japanese text-to-speech model using Rectified Flow Diffusion Transformer architecture that enables "Voice Design" - controlling speaker voice, emotion, and style through descriptive text captions rather than requiring reference audio for voice cloning. The model uniquely combines caption-based voice control with emoji annotations embedded in input text for fine-grained style adjustment, trained on Japanese speech data with comprehensive audio characteristic descriptions. Key limitations include Japanese-only support and relatively weak Kanji reading accuracy compared to similar-sized TTS models.

**Key points:**

- Introduces Voice Design capability that generates diverse voices through descriptive text captions without requiring reference audio, replacing traditional voice cloning approaches
- Combines caption-based voice conditioning with emoji-based style control for granular control over speaking styles, emotions, and sound effects during generation
- Uses Rectified Flow Diffusion Transformer (RF-DiT) architecture over continuous DACVAE latents for high-quality 48kHz Japanese speech synthesis
- Training data was enriched with comprehensive text captions generated using fine-tuned Qwen models, enabling the Voice Design functionality
- Notable limitation: Kanji reading accuracy is relatively weak compared to other TTS models of similar size, requiring preprocessing of complex Kanji to Hiragana/Katakana

### [k2-fsa/OmniVoice](https://huggingface.co/k2-fsa/OmniVoice)

**Relevance:** 70.0%

OmniVoice is a zero-shot multilingual text-to-speech model built on a diffusion language model architecture, supporting over 600 languages with voice cloning and controllable voice design capabilities. The key differentiator is its exceptionally broad language coverage (the widest among zero-shot TTS models) combined with fast inference speeds (RTF 0.025) and the ability to control speaker attributes like gender, age, and accent. The model is based on Qwen3-0.6B and uses a streamlined diffusion-based approach for both quality and efficiency.

**Key points:**

- OmniVoice supports 600+ languages, representing the broadest language coverage among zero-shot TTS models
- Novel diffusion language model architecture designed specifically for text-to-speech synthesis
- Achieves extremely fast inference with RTF as low as 0.025 (40x faster than real-time)
- Combines voice cloning capabilities with controllable voice design via speaker attributes (gender, age, pitch, dialect, whisper)
- Built on Qwen3-0.6B base model with a clean, streamlined, and scalable architecture that delivers both quality and speed
