### [StyleStream: Real-Time Zero-Shot Voice Style Conversion](https://arxiv.org/abs/2602.20113)

**Relevance:** 70.0%

StyleStream presents the first real-time zero-shot voice style conversion system that transforms speech to match a target speaker's timbre, accent, and emotion while preserving linguistic content. The system uses a two-stage approach: a "Destylizer" that removes style attributes and a "Stylizer" (diffusion transformer) that reintroduces target style, with content-style separation enforced through text supervision and constrained information bottlenecks. The key advancement is achieving state-of-the-art conversion quality with real-time processing (1-second end-to-end latency) through a fully non-autoregressive architecture, addressing a gap where previous work focused only on offline conversion.

**Key points:**

- StyleStream is the first streamable zero-shot voice style conversion system that achieves real-time performance with 1 second end-to-end latency
- Novel two-component architecture: Destylizer removes style while preserving content, and Stylizer (diffusion transformer) reintroduces target style conditioned on reference speech
- Robust content-style disentanglement enforced through text supervision and highly constrained information bottleneck
- Fully non-autoregressive architecture enables real-time conversion, addressing a gap in prior work which had limited quality and no real-time capabilities

### [CosyAccent: Duration-Controllable Accent Normalization Using Source-Synthesis Training Data](https://arxiv.org/abs/2602.19166)

**Relevance:** 70.0%

CosyAccent introduces a novel "source-synthesis" training approach for accent normalization that uses generated L2 speech paired with authentic native speech as targets, eliminating the need for real L2 data during training. The method differs from existing work by avoiding TTS artifacts in training data and employing a non-autoregressive architecture that provides explicit duration control while maintaining prosodic naturalness through implicit rhythm modeling. A potential limitation is the reliance on synthetic L2 speech quality and possible domain mismatch when processing real-world accented speech at inference time.

**Key points:**

- Introduces novel 'source-synthesis' training methodology that generates source L2 speech and uses authentic native speech as targets, eliminating the need for real L2 data during training and avoiding TTS artifacts
- CosyAccent is a non-autoregressive model that resolves the trade-off between prosodic naturalness and duration control by implicitly modeling rhythm while providing explicit duration control
- Despite being trained without any real L2 speech data, CosyAccent achieves significantly improved content preservation and superior naturalness compared to strong baselines trained on real-world data
- Addresses key limitations in existing accent normalization systems that suffer from unnatural outputs and content distortion due to suboptimal training data and rigid duration modeling

### [inclusionAI/Ming-omni-tts-16.8B-A3B](https://huggingface.co/inclusionAI/Ming-omni-tts-16.8B-A3B)

**Relevance:** 70.0%

Ming-omni-tts is a 16.8B parameter unified audio generation model that synthesizes speech, environmental sounds, and music in a single autoregressive framework, using a custom 12.5Hz continuous tokenizer with "Patch-by-Patch" compression for efficient inference (3.1Hz frame rate). The model distinguishes itself by providing fine-grained control over speech attributes (pitch, emotion, dialect, etc.) while supporting zero-shot voice cloning and mathematical/chemical text normalization, claiming to be the first autoregressive model for joint speech-sound-music generation. The model card presents extensive benchmark results but doesn't explicitly discuss limitations or failure cases.

**Key points:**

- Industry's first autoregressive model to jointly generate speech, ambient sound, and music in a single channel using custom 12.5Hz continuous tokenizer and DiT head architecture
- Patch-by-Patch compression strategy reduces LLM inference frame rate to 3.1Hz, significantly cutting latency while preserving audio quality and naturalness
- Achieves exceptional dialect control with 93% accuracy for Cantonese and emotion control accuracy of 46.7%, surpassing existing models like CosyVoice3
- Demonstrates superior zero-shot voice cloning performance with 0.83% WER on Seed-tts-eval, outperforming SeedTTS and GLM-TTS
- Features robust text normalization capabilities for complex mathematical and chemical expressions with 1.97% CER, comparable to Gemini-2.5 Pro performance
