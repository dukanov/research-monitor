### [EMORL-TTS: Reinforcement Learning for Fine-Grained Emotion Control in LLM-based TTS](https://arxiv.org/abs/2510.05758)

**Релевантность:** 75.0%

EMORL-TTS предлагает использовать обучение с подкреплением для тонкого управления эмоциями в TTS-системах на основе больших языковых моделей, объединяя глобальный контроль интенсивности в пространстве VAD с локальной регуляцией акцентов. Основное отличие от существующих подходов — преодоление ограничений дискретных речевых токенов через RL с целевыми функциями вознаграждения для категории эмоций, интенсивности и расстановки акцентов. Метод показывает улучшение точности эмоций и дифференциации интенсивности при сохранении качества синтеза.

**Ключевые моменты:**

- Предложена новая архитектура EMORL-TTS, использующая обучение с подкреплением для точного контроля эмоций в TTS-системах на основе больших языковых моделей
- В отличие от существующих подходов с дискретными токенами речи, система объединяет глобальный контроль интенсивности в VAD-пространстве с локальной регуляцией акцентов
- Метод комбинирует контролируемое обучение с обучением с подкреплением, используя специфические награды для категории эмоций, интенсивности и акцентирования
- Исследовано влияние размещения акцентов на тонкую настройку интенсивности эмоций в речевом синтезе
- Эксперименты показывают улучшение точности эмоций, дифференциации интенсивности и ясности акцентов при сохранении качества синтеза на уровне сильных базовых моделей

### [OneVoice: One Model, Triple Scenarios-Towards Unified Zero-shot Voice Conversion](https://arxiv.org/abs/2601.18094)

**Релевантность:** 70.0%

**OneVoice** представляет единую модель для zero-shot преобразования голоса, способную работать с тремя сценариями (лингвистически-сохраняющее, экспрессивное и певческое преобразование) вместо использования отдельных специализированных моделей. Ключевые отличия включают архитектуру Mixture-of-Experts с двухпутевой маршрутизацией для моделирования общих и сценарий-специфичных знаний, а также двухэтапное обучение с LoRA-экспертами для решения проблемы дисбаланса данных (много речи, мало пения). Авторы утверждают, что модель достигает производительности специализированных решений во всех трех сценариях при быстрой генерации за 2 шага.

**Ключевые моменты:**

- OneVoice представляет собой единую архитектуру для конвертации голоса, способную обрабатывать три сценария (лингвистически-сохраняющий, выразительный и вокальный) в рамках одной модели, в отличие от существующих специализированных решений
- Модель использует Mixture-of-Experts (MoE) с двухпутевым механизмом маршрутизации, включающим изоляцию общих экспертов и назначение доменных экспертов с учетом сценария
- Применяется VAE-free next-patch диффузия с непрерывной языковой моделью для обеспечения высокого качества и эффективного моделирования последовательностей
- OneVoice демонстрирует производительность на уровне или превышающую специализированные модели во всех трех сценариях, при этом предлагая быструю генерацию всего за 2 шага
- Для решения проблемы дисбаланса данных (обилие речи против недостатка вокальных данных) используется двухэтапное прогрессивное обучение с LoRA-адаптерами для доменных экспертов

### [Reflecting Twice before Speaking with Empathy: Self-Reflective Alternating Inference for Empathy-Aware End-to-End Spoken Dialogue](https://arxiv.org/abs/2601.18281)

**Релевантность:** 70.0%

Авторы предлагают ReEmpathy — модель для эмпатичного диалога, которая использует механизм "саморефлексивного чередующегося вывода": модель сначала размышляет об эмпатии в свободной форме, а затем генерирует ответ. В отличие от существующих подходов, которые полагаются на жёсткие числовые оценки или эталонные ответы, система использует описательную естественно-языковую оценку эмпатии (EmpathyEval), поскольку "правильного" эмпатичного ответа не существует. Эксперименты показывают улучшение качества эмпатичного диалога благодаря рефлексивному рассуждению.

**Ключевые моменты:**

- Предложен механизм «Эмпатического Саморефлексивного Чередующегося Вывода», который чередует генерацию речевых ответов с рефлексивными рассуждениями об эмпатии
- Разработана модель оценки EmpathyEval на основе естественного языка для описательной оценки эмпатического качества в разговорной речи, отходя от жестких числовых метрик
- Ключевое понимание: не существует единственного «правильного» эмпатического ответа, а простые числовые оценки не могут полностью отразить нюансы эмоционального выражения
- Текущие подходы ограничены зависимостью от жестких контролируемых сигналов (эталонные ответы, оценки предпочтений), что фундаментально неподходит для моделирования сложной эмпатии
- Экспериментально показано существенное улучшение эмпатически-чувствительного разговорного диалога через включение рефлексивных рассуждений

### [AR-Omni: A Unified Autoregressive Model for Any-to-Any Generation](https://arxiv.org/abs/2601.17761)

**Релевантность:** 70.0%

AR-Omni представляет единую авторегрессивную модель для генерации любых модальностей (текст, изображения, речь) с использованием одного Transformer-декодера без дополнительных экспертных компонентов. В отличие от существующих мультимодальных систем, которые полагаются на специализированные декодеры для разных модальностей, AR-Omni использует единый поток токенов и цель предсказания следующего токена. Модель демонстрирует хорошее качество во всех трех модальностях при сохранении работы в реальном времени (коэффициент 0.88 для генерации речи).

**Ключевые моменты:**

- AR-Omni представляет единую авторегрессионную модель для генерации любой модальности в любую (текст, изображение, речь) без использования экспертных декодеров, в отличие от существующих омни-MLLM
- Модель использует один Transformer-декодер для всех модальностей с единым потоком токенов и единой целевой функцией следующего токена, что обеспечивает элегантность и масштабируемость
- Авторы решают три практические проблемы: дисбаланс модальностей через перевзвешивание потерь, визуальную точность через перцептивную потерю на уровне токенов, и баланс стабильности-креативности через механизм декодирования с конечными состояниями
- Модель достигает высокого качества во всех трех модальностях при сохранении режима реального времени с коэффициентом 0.88 для генерации речи

### [Hearing Between the Lines: Unlocking the Reasoning Power of LLMs for Speech Evaluation](https://arxiv.org/abs/2601.13742)

**Релевантность:** 70.0%

Авторы предлагают TRACE — фреймворк для оценки речевых систем, который позволяет текстовым LLM анализировать аудио через текстовые описания акустических признаков, избегая дорогих аудио-языковых моделей. Ключевое отличие — разделение оценки на три измерения (содержание, качество голоса, паралингвистика) с использованием аннотаций Human Chain-of-Thought и создание "текстового чертежа" аудиосигналов для рассуждений LLM. Подход показывает лучшее согласие с человеческими оценщиками при значительно меньших затратах по сравнению с ALM.

**Ключевые моменты:**

- Предложена новая система TRACE, которая позволяет языковым моделям анализировать аудиосигналы через текстовые представления для оценки речи, избегая дорогостоящих аудио-языковых моделей
- Введен протокол аннотации Human Chain-of-Thought (HCoT), который разделяет оценку речи на три явные измерения: содержание, качество голоса и паралингвистика
- TRACE показывает более высокое согласие с человеческими экспертами по сравнению с аудио-языковыми моделями и LLM-судьями, работающими только с транскриптами, при значительно меньших затратах
- Система создает текстовый 'чертеж' недорогих аудиосигналов и использует детерминистическую политику для объединения оценок по разным измерениям в общий рейтинг
