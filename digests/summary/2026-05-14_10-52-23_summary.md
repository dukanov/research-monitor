🤖 **ResembleAI/Dramabox** — Dramabox introduces a prompt-driven approach to expressive text-to-speech synthesis, where performance directions (emotions, vocal effects, pauses) are embedded directly within the text prompt using a structured format with dialogue in quotes and stage directions outside. This differs from traditional TTS systems that separate text content from prosodic control mechanisms, instead unifying both aspects into a single prompt interface built on the LTX-2.3 diffusion transformer architecture. The system is specifically optimized for dramatic and theatrical speech applications rather than general-purpose neutral speech synthesis. [Link](https://huggingface.co/ResembleAI/Dramabox)
