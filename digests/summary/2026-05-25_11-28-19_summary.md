📄 **AffectCodec: Emotion-Preserving Neural Speech Codec with Block-Diagonal Residual FSQ** — Introduces a neural speech codec that explicitly preserves emotional information during compression using Block-Diagonal Residual Finite Scalar Quantization (BD-RFSQ), which structurally separates emotion and acoustic subspaces. Unlike existing codecs that optimize primarily for acoustic reconstruction and implicitly allocate bits, this approach provides explicit structural guarantees for emotion preservation through block-diagonal projections. Shows improved emotion preservation at low bitrates while maintaining competitive acoustic quality. [Link](https://arxiv.org/abs/2605.23373)

📄 **UniSRM: A Unified Speech Reward Model for Reasoning-Based Fine-grained Assessment** — Proposes a unified speech reward model that evaluates speech generation across multiple dimensions using a two-stage reasoning-based assessment pipeline to replace expensive human judgments. Unlike existing AudioLLM-based judges that target narrow scenarios, UniSRM provides comprehensive, interpretable evaluation across diverse speech generation tasks through new datasets and "Reasoning-Consistent Rewards." Addresses the scalability challenge of speech evaluation by moving beyond utterance-level quality to context-level coherence assessment. [Link](https://arxiv.org/abs/2605.23261)

📄 **StepAudio 2.5 Technical Report** — Presents a unified audio-language foundation model that handles ASR, TTS, and real-time dialogue using a single shared backbone with task-specific "operational regimes" rather than separate architectures. The key innovation is using Reinforcement Learning from Human Feedback (RLHF) as the primary post-training mechanism to shape the shared model into distinct operational modes for each speech task. Claims to match or exceed specialized systems across all three capabilities, which existing unified models have struggled to achieve. [Link](https://arxiv.org/abs/2605.23463)
