📄 **DARS: Dysarthria-Aware Rhythm-Style Synthesis for ASR Enhancement** — DARS introduces a specialized TTS framework that generates synthetic dysarthric speech for ASR data augmentation, using a multi-stage rhythm predictor with contrastive learning and dysarthric-style conditional flow matching. Unlike existing TTS augmentation methods that treat dysarthric speech as generic variation, DARS explicitly models the abnormal prosody and rhythm patterns characteristic of pathological speech. Evaluation on the TORGO dataset shows 54% relative WER reduction when using the synthetic dysarthric data for ASR model adaptation. [Link](https://arxiv.org/abs/2603.01369)

📄 **S-VoCAL: A Dataset and Evaluation Framework for Inferring Speaking Voice Character Attributes in Literature** — S-VoCAL presents the first dataset and evaluation framework for automatically inferring voice-related character attributes from literary text to improve synthetic audiobook narration. The dataset contains 952 character-book pairs with 8 sociophonetically-grounded attributes and introduces an LLM embedding-based similarity metric for evaluation. Initial experiments with a RAG pipeline show reliable performance on basic attributes like age and gender but struggle with more complex characteristics such as origin and physical health. [Link](https://arxiv.org/abs/2603.00958)
