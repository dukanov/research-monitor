📄 **Fed-PISA: Federated Voice Cloning via Personalized Identity-Style Adaptation** — Introduces a federated learning framework for voice cloning that disentangles speaker identity and style features using Low-Rank Adaptation, keeping identity features local while sharing only lightweight style features with the server. Unlike existing federated voice cloning approaches that suppress client heterogeneity, Fed-PISA preserves stylistic diversity through collaborative filtering-inspired aggregation, creating personalized models based on stylistically similar clients. [Link](https://arxiv.org/abs/2509.16010)

📄 **Emotion-Aligned Generation in Diffusion Text to Speech Models via Preference-Guided Optimization** — Presents EASPO, a post-training framework that improves emotional control in diffusion-based TTS by optimizing at intermediate denoising steps rather than only at the final output level. The method employs a time-conditioned preference model (EASPM) that scores noisy intermediate speech states, enabling fine-grained emotional control during generation. This differs from existing approaches that rely on coarse emotional labels or proxy classifiers and only receive utterance-level feedback. [Link](https://arxiv.org/abs/2509.25416)
