📄 **MambaVoiceCloning: Efficient and Expressive Text-to-Speech via State-Space Modeling and Diffusion Control** — This work presents the first fully state-space model approach for TTS conditioning, using Mamba architecture for text encoding, temporal modeling, and prosody control while maintaining diffusion-based mel-spectrogram generation. Unlike previous Mamba-TTS hybrids that retain attention mechanisms, this achieves linear time complexity and bounded memory usage for all conditioning components, though diffusion processing remains the primary inference bottleneck. [Link](https://arxiv.org/abs/2604.00292)

📄 **Measuring Prosody Diversity in Zero-Shot TTS: A New Metric, Benchmark, and Exploration** — The paper introduces DS-WED (Discretized Speech Weighted Edit Distance), a new prosody diversity metric using weighted edit distance over semantic speech tokens, alongside ProsodyEval, a human-rated dataset of 1000 TTS samples. DS-WED demonstrates substantially higher correlation with human prosody judgments compared to existing acoustic metrics and reveals limited prosodic variation capabilities in current large audio language models. [Link](https://arxiv.org/abs/2509.19928)

🤖 **Aratako/Irodori-TTS-500M-v2-VoiceDesign** — This Japanese TTS model implements "Voice Design" through descriptive text captions rather than reference audio for voice control, using Rectified Flow Diffusion Transformer architecture. The approach combines caption-based voice control with emoji annotations for fine-grained style adjustment, differing from traditional voice cloning methods that require audio samples. [Link](https://huggingface.co/Aratako/Irodori-TTS-500M-v2-VoiceDesign)

🤖 **HumeAI/mlx-tada-3b** — TADA implements "text-acoustic dual alignment" to create a unified speech-language model with 1:1 synchronization between speech and text representations in a single coherent stream, built on Llama 3.2 3B. This integrated dual-alignment approach treats speech and text as unified rather than separate modalities, supporting 10 languages with optimization for Apple Silicon hardware. [Link](https://huggingface.co/HumeAI/mlx-tada-3b)

🤖 **k2-fsa/OmniVoice** — OmniVoice provides zero-shot multilingual TTS with exceptionally broad language coverage (600+ languages) using a diffusion language model architecture based on Qwen3-0.6B. The model distinguishes itself through this wide language support combined with fast inference (RTF 0.025) and controllable voice design for speaker attributes like gender, age, and accent without requiring reference audio. [Link](https://huggingface.co/k2-fsa/OmniVoice)
