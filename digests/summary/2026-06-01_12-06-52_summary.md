📄 **Chatterbox-Flash: Prior-Calibrated Block Diffusion for Streaming Zero-Shot TTS** — This work converts pretrained autoregressive TTS models into block-diffusion decoders that generate tokens in parallel within blocks while maintaining streaming capability. The key innovation addresses quality degradation from naive block diffusion by using prior-calibrated scoring to correct biases toward high-frequency tokens in long-tail distributions. [Link](https://arxiv.org/abs/2605.30748)

📄 **UniAudio-Token: Empowering Semantic Speech Tokenizers with General Audio Perception** — This framework extends semantic speech tokenizers to handle general audio perception beyond speech while preserving linguistic capabilities through Semantic-Acoustic Primitives and content-aware gating. Unlike approaches that redesign tokenizers from scratch, it works within existing semantic paradigms and maintains compact single-codebook design while addressing acoustic blindness. [Link](https://arxiv.org/abs/2605.31521)

📄 **UNISON: A Unified Sound Generation and Editing Framework via Deep LLM Fusion** — UNISON presents a single latent diffusion model that handles seven audio tasks using layer-wise deep LLM fusion, injecting hidden states from frozen MLLM layers into MM-DiT blocks for improved semantic conditioning. The unified architecture uses channel-wise masks for task encoding and achieves competitive performance with specialist models while being ~4× smaller than comparable unified systems. [Link](https://arxiv.org/abs/2605.31530)

📄 **OpenSTBench: Beyond Semantic Evaluation for Speech Translation** — This framework provides unified evaluation of speech translation systems across multiple dimensions (translation quality, speech quality, temporal consistency, latency) in a single protocol for both speech-to-text and speech-to-speech systems. Unlike existing approaches that evaluate aspects separately under different protocols, it organizes heterogeneous outputs into a shared format enabling direct cross-system comparison. [Link](https://arxiv.org/abs/2605.30792)

📄 **ImmersiveTTS: Environment-Aware Text-to-Speech with Multimodal Diffusion Transformer** — This system generates speech naturally integrated with environmental audio contexts using a multimodal diffusion transformer with joint attention mechanisms between speech and environmental sounds. Unlike conventional TTS that generates speech in isolation, it explicitly models cross-modal interactions and uses domain-specific representation alignment to maintain semantic consistency across modalities. [Link](https://arxiv.org/abs/2605.30965)

📄 **SwanVoice: Expressive Long-Form Zero-Shot Speech Synthesis for Both Monologue and Dialogue** — SwanVoice directly synthesizes multi-speaker dialogue (1-4 speakers) in a single pass using flow-matching diffusion with speaker-turn conditioning and progressive training from monologue to dialogue data. This differs from existing approaches that synthesize dialogue turns separately and concatenate outputs, which breaks acoustic consistency and conversational coherence. [Link](https://arxiv.org/abs/2605.30993)

📄 **Comprehensive Benchmarking of Long-Form Speech Generation in Diverse Scenarios** — SwanBench-Speech introduces a benchmark with 1,101 samples across 17 speech scenarios using 7 automated metrics for acoustics, semantics, and expressiveness evaluation. Unlike existing benchmarks focusing on limited domains and basic quality measures, this specifically addresses long-context challenges like consistency and coherence critical for real-world applications. [Link](https://huggingface.co/papers/2605.28618)

🤖 **CosyVoice-300M-SFT** — CosyVoice integrates large language model architecture with TTS for zero-shot multilingual synthesis across 9 languages and 18+ Chinese dialects with cross-lingual voice cloning capabilities. The system differentiates itself through LLM-based features including pronunciation inpainting and bi-directional streaming with 150ms latency, moving beyond traditional TTS architectures. [Link](https://huggingface.co/FunAudioLLM/CosyVoice-300M-SFT)

🤖 **CosyVoice-300M-Instruct** — This variant of CosyVoice adds instruction-following capabilities, allowing users to control synthesis parameters (language, dialect, emotion, speed) through natural language prompts. The innovation lies in combining LLM architecture with speech synthesis to enable intuitive parameter control, contrasting with traditional TTS systems that require explicit parameter specification. [Link](https://huggingface.co/FunAudioLLM/CosyVoice-300M-Instruct)
