📄 **OneVoice: One Model, Triple Scenarios-Towards Unified Zero-shot Voice Conversion** — Представляет единую модель для zero-shot преобразования голоса, способную работать с тремя сценариями: лингвистически-сохраняющим, экспрессивным и певческим преобразованием. Использует архитектуру Mixture-of-Experts с двухпутевой маршрутизацией для моделирования общих и сценарий-специфичных знаний, в отличие от отдельных специализированных моделей. Применяет двухэтапное обучение с LoRA-экспертами для решения проблемы дисбаланса данных между речью и пением. [Link](https://arxiv.org/abs/2601.18094)

📄 **Reflecting Twice before Speaking with Empathy: Self-Reflective Alternating Inference for Empathy-Aware End-to-End Spoken Dialogue** — Предлагает ReEmpathy — модель эмпатичного диалога с механизмом саморефлексивного чередующегося вывода, где система сначала размышляет об эмпатии, а затем генерирует ответ. В отличие от существующих подходов с жёсткими числовыми оценками, использует описательную естественно-языковую оценку эмпатии (EmpathyEval). Показывает улучшение качества эмпатичного диалога благодаря рефлексивному рассуждению. [Link](https://arxiv.org/abs/2601.18281)

📄 **EMORL-TTS: Reinforcement Learning for Fine-Grained Emotion Control in LLM-based TTS** — Применяет обучение с подкреплением для тонкого управления эмоциями в TTS-системах на основе больших языковых моделей, объединяя глобальный контроль интенсивности в пространстве VAD с локальной регуляцией акцентов. Преодолевает ограничения дискретных речевых токенов через RL с целевыми функциями вознаграждения для категории эмоций, интенсивности и расстановки акцентов. Демонстрирует улучшение точности эмоций и дифференциации интенсивности при сохранении качества синтеза. [Link](https://arxiv.org/abs/2510.05758)

📄 **AR-Omni: A Unified Autoregressive Model for Any-to-Any Generation** — Представляет единую авторегрессивную модель для генерации текста, изображений и речи через один Transformer-декодер без дополнительных экспертных компонентов. В отличие от существующих мультимодальных систем со специализированными декодерами, использует единый поток токенов и цель предсказания следующего токена для всех модальностей. Достигает коэффициента реального времени 0.88 для генерации речи при сохранении качества во всех трех модальностях. [Link](https://arxiv.org/abs/2601.17761)

📄 **Hearing Between the Lines: Unlocking the Reasoning Power of LLMs for Speech Evaluation** — Предлагает TRACE — фреймворк для оценки речевых систем, позволяющий текстовым LLM анализировать аудио через текстовые описания акустических признаков. Разделяет оценку на три измерения (содержание, качество голоса, паралингвистика) с использованием аннотаций Human Chain-of-Thought и создает "текстовый чертёж" аудиосигналов для рассуждений LLM. Показывает лучшее согласие с человеческими оценщиками при значительно меньших затратах по сравнению с аудио-языковыми моделями. [Link](https://arxiv.org/abs/2601.13742)
