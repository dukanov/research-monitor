📄 **ParaMETA: Towards Learning Disentangled Paralinguistic Speaking Styles Representations from Speech** — Предлагает единый фреймворк для изучения разделённых представлений различных стилей речи (эмоции, возраст, пол, язык) путём проекции в специальные подпространства для каждого типа. В отличие от существующих подходов с отдельными моделями, метод снижает взаимное влияние задач и позволяет одной модели выполнять как распознавание, так и контролируемую генерацию с изменением отдельных характеристик. [Ссылка](https://arxiv.org/abs/2601.12289)

📄 **A Unified Neural Codec Language Model for Selective Editable Text to Speech Generation** — Представляет SpeechEdit — модель на основе нейронных кодеков, которая может выборочно изменять только указанные атрибуты (тембр, просодию), сохраняя остальные неизменными. В отличие от существующих подходов zero-shot синтеза, которые полностью имитируют все акустические характеристики из промпта, обеспечивает гибкий локализованный контроль при сохранении естественности. Модель обучена на новом датасете LibriEdit с парами для обучения на основе разностей. [Ссылка](https://arxiv.org/abs/2601.12480)

📄 **Lombard Speech Synthesis for Any Voice with Controllable Style Embeddings** — Разработана система синтеза речи с эффектом Ломбарда (адаптация для шумных условий) для любого говорящего без использования специальных данных Ломбарда при обучении. Ключевая особенность — использование анализа главных компонент для выделения и управления компонентами стилевых эмбеддингов, связанными с характеристиками эффекта Ломбарда. Система обеспечивает сохранение естественности, идентичности говорящего и точный просодический контроль. [Ссылка](https://arxiv.org/abs/2601.12966)

📄 **Emotional Dimension Control in Language Model-Based Text-to-Speech: Spanning a Broad Spectrum of Human Emotions** — Предлагает языковую модель для синтеза речи с управлением эмоциональностью через три непрерывных измерения (удовольствие, возбуждение, доминирование) вместо дискретных категорий. Ключевое отличие — обучение предиктора эмоциональных измерений, который переводит категориальные метки в непрерывное PAD-пространство. Это позволяет генерировать более широкий спектр эмоциональных стилей при использовании существующих датасетов с категориальными метками. [Ссылка](https://arxiv.org/abs/2409.16681)

📄 **DAIEN-TTS: Disentangled Audio Infilling for Environment-Aware Text-to-Speech Synthesis** — Представляет zero-shot TTS систему, которая независимо контролирует тембр говорящего и фоновую среду через раздельные промпты, используя предобученный модуль разделения с заполнением замаскированных участков. Ключевое отличие — возможность одновременного синтеза персонализированной речи и изменяющейся во времени фоновой среды с помощью двойного classifier-free guidance. Система показала высокую естественность, сходство с целевым говорящим и точность воспроизведения окружающей среды. [Ссылка](https://arxiv.org/abs/2509.14684)

📄 **Objective Evaluation of Prosody and Intelligibility in Speech Synthesis via Conditional Prediction of Discrete Tokens** — Предлагает TTScore — метод оценки синтезированной речи, основанный на условном предсказании дискретных речевых токенов для измерения разборчивости и просодии без эталонного аудио. В отличие от существующих метрик типа WER и F0-RMSE, которые слабо коррелируют с человеческим восприятием, использует два отдельных предиктора последовательность-в-последовательность. Эксперименты показали более сильную корреляцию с человеческими оценками качества по сравнению с традиционными метриками. [Ссылка](https://arxiv.org/abs/2509.20485)
