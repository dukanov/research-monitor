📄 **AffectCodec: Emotion-Preserving Neural Speech Codec for Expressive Speech Modeling** — Introduces a neural speech codec that explicitly preserves emotional information during compression using emotion-semantic guided latent modulation and distillation techniques. Unlike existing codecs that primarily optimize acoustic reconstruction and often lose emotional cues during quantization, this approach integrates emotion preservation directly into the codec design while maintaining content accuracy. [Link](https://arxiv.org/abs/2605.11098)

📄 **Exploring Token-Space Manipulation in Latent Audio Tokenizers** — LATTE uses a fixed set of learnable latent tokens that aggregate global utterance information rather than typical frame-level token sequences. This compact, non-temporally aligned bottleneck enables simple token-space interventions like swapping positions between utterances to modify global attributes such as speaker identity and background noise. The approach maintains competitive reconstruction quality while enabling controllable audio manipulation without requiring task-specific supervised models. [Link](https://arxiv.org/abs/2605.11192)

📄 **AuDirector: A Self-Reflective Closed-Loop Framework for Immersive Audio Storytelling** — A multi-agent framework for generating long-form audio narratives that uses identity-aware preprocessing to match character profiles with appropriate voices and guided emotional synthesis. The key innovation is a closed-loop self-correction mechanism that automatically detects and regenerates defective audio components, combined with human-guided refinement through natural language feedback. This addresses common issues in audio storytelling like voice-character mismatches and lack of quality control. [Link](https://arxiv.org/abs/2605.11866)

📄 **Poly-SVC: Polyphony-Aware Singing Voice Conversion with Harmonic Modeling** — A singing voice conversion system that can process accompanied recordings with residual harmonies, unlike existing methods that require clean vocals and only capture lead melodies. Uses a Constant-Q Transform-based pitch extractor to preserve both lead melody and harmonic content, combined with a diffusion decoder using Conditional Flow Matching. Experiments show superior performance in naturalness, timbre similarity, and harmony reconstruction on both harmony-rich and single-melody recordings. [Link](https://arxiv.org/abs/2605.12310)

📄 **Towards Fine-Grained Multi-Dimensional Speech Understanding: Data Pipeline, Benchmark, and Model** — Addresses limitations in current speech LLMs that struggle with fine-grained, multi-dimensional speech understanding beyond basic recognition. Proposes a three-part solution: a data curation pipeline for spontaneous speech, FMSU-Bench (14-dimension speech attribute benchmark), and FM-Speech model using decoupled attribute modeling with progressive curriculum fine-tuning. The systematic approach moves beyond coarse-grained processing to handle complex features like micro-acoustic cues and paralinguistic signals. [Link](https://arxiv.org/abs/2605.12036)

🤖 **Irodori-TTS-500M-v2-Character-Voice-SigLIP** — A Japanese TTS model that uses character images instead of reference audio to control voice characteristics, building on rectified flow diffusion transformer architecture. Unlike traditional voice cloning approaches requiring audio samples, it extracts visual features from character images using SigLIP encoder to guide vocal quality and speaking style. The approach relies on subjective visual impressions from character images to determine appropriate voice characteristics. [Link](https://huggingface.co/p1atdev/Irodori-TTS-500M-v2-Character-Voice-SigLIP)

🤖 **Irodori-TTS-500M-v2-Character-Voice-Tagger** — A Japanese TTS model that replaces traditional speaker conditioning with character image conditioning, using visual features to control vocal quality instead of reference audio clips. Unlike the base Irodori-TTS model which performs zero-shot voice cloning with audio references, this variant extracts features from character images via a wd-vit-tagger-v3 encoder. The approach is novel but relies on subjective interpretation of how character appearance should map to vocal characteristics. [Link](https://huggingface.co/p1atdev/Irodori-TTS-500M-v2-Character-Voice-Tagger)
