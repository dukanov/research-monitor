📄 **X-Voice: Enabling Everyone to Speak 30 Languages via Zero-Shot Cross-Lingual Voice Cloning** — X-Voice achieves multilingual voice cloning across 30 languages using a 0.4B parameter model trained with IPA as unified phonetic representation. The key innovation is a two-stage training paradigm that fine-tunes on synthesized audio pairs with masked text prompts, eliminating the need for reference audio transcripts during inference while matching the performance of much larger billion-scale models. [Link](https://arxiv.org/abs/2605.05611)

📄 **Minimizing Modality Gap from the Input Side: Your Speech LLM Can Be a Prosody-Aware Text LLM** — TextPro-SLM reduces the speech-text modality gap by focusing on the input representation rather than output generation, using a unified encoder (WhisperPro) that produces both text tokens and prosody embeddings for the LLM backbone. This approach inverts the typical paradigm by making speech input resemble prosody-aware text rather than making speech generation more text-like, achieving strong performance with only ~1,000 hours of training data. [Link](https://arxiv.org/abs/2605.05927)

📄 **WavCube: Unifying Speech Representation for Understanding and Generation via Semantic-Acoustic Joint Modeling** — WavCube creates a unified speech representation supporting both understanding and generation tasks by combining semantic and acoustic information in a continuous latent space derived from SSL encoders. The method uses a two-stage approach: first creating a semantic bottleneck to filter redundant information, then injecting acoustic details while maintaining semantic grounding through anchoring loss, achieving 8x compression while preserving performance across diverse speech tasks. [Link](https://arxiv.org/abs/2605.06407)

📄 **MiniCPM-o 4.5: Towards Real-Time Full-Duplex Omni-Modal Interaction** — MiniCPM-o 4.5 introduces "Omni-Flow," a streaming framework that enables real-time full-duplex multimodal interaction by aligning vision, audio, and text along a shared temporal axis. Unlike existing turn-based multimodal models, this 9B parameter system can simultaneously perceive and respond, supporting proactive behaviors based on continuous scene understanding rather than reactive alternating between listening and speaking phases. [Link](https://huggingface.co/papers/2604.27393)
