📄 **StyleStream: Real-Time Zero-Shot Voice Style Conversion** — This system achieves real-time voice style conversion with 1-second end-to-end latency while transforming timbre, accent, and emotion without linguistic content changes. Unlike previous offline-only methods, StyleStream uses a fully non-autoregressive architecture with separated "Destylizer" and "Stylizer" components to maintain state-of-the-art quality during real-time processing. [Link](https://arxiv.org/abs/2602.20113)

📄 **CosyAccent: Duration-Controllable Accent Normalization Using Source-Synthesis Training Data** — The method trains accent normalization models using synthetic L2 speech paired with authentic native speech targets, eliminating the need for real accented data during training. This "source-synthesis" approach differs from existing work by avoiding TTS artifacts in training data and employs a non-autoregressive architecture with explicit duration control for prosodic naturalness. [Link](https://arxiv.org/abs/2602.19166)

🤖 **Ming-omni-tts-16.8B-A3B** — This 16.8B parameter model unifies speech, environmental sound, and music generation within a single autoregressive framework using a custom 12.5Hz continuous tokenizer. The system distinguishes itself by jointly generating multiple audio types while providing fine-grained control over speech attributes including pitch, emotion, and dialect, claiming to be the first autoregressive model for unified audio generation. [Link](https://huggingface.co/inclusionAI/Ming-omni-tts-16.8B-A3B)

🤖 **Ming-omni-tts-0.5B** — This smaller 0.5B parameter version of the unified audio generation model synthesizes speech, environmental sounds, and music through the same autoregressive architecture and custom tokenizer. While maintaining the joint generation capabilities and fine-grained speech control of its larger counterpart, the model shows limitations in emotion control accuracy at 46.7%, indicating areas for improvement in expressive synthesis tasks. [Link](https://huggingface.co/inclusionAI/Ming-omni-tts-0.5B)
